# BAT: 1000 path

Downstream evidence for the 1,000 BAT Ethereum outflow. Includes public router context; unrelated router movements are not attributed to the vault.

Raw response bytes and request files are retained. Per-request capture metadata records public source URLs, UTC and transport status where available; private connection details are omitted. A successful HTTP response may still contain an RPC error. The SHA-256 manifest checks byte integrity, not source truth. See [the BAT assessment](../../research/assets/bat.md) and configuration for selected inputs and limitations. No community submissions are included.
