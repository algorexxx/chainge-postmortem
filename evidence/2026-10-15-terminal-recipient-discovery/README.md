# Terminal recipient discovery

Bounded recipient-history discovery for the expanded BUSD/USDC material closing shortlist. Ethereum token-filtered explorer pagination retains terminal cursors; Arbitrum, Optimism and Avalanche use saved bounded numeric RPC ranges. This is a tracing aid, not proof of complete recipient history or allocation of mixed funds.

Requests, raw responses and capture metadata are retained with a saved-byte SHA-256 manifest. Acquisition used anonymous public sources. Successful state, event coverage, receipt verification, token backing and accepted settlement are separate checks.
