# Anonymous USDC recipient discovery

Public Blockscout Ethereum token-transfer pagination, captured 2026-10-13. Requests retain source URLs and retrieval times. All returned pages were obtained for each queried address; this is explorer discovery, not independently complete chain history. Selected transfers are corroborated in the late-context and late-endpoint-context packages. These addresses are downstream recipients, not automatically custody addresses.
