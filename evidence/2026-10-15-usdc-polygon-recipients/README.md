# Usdc polygon recipients

Broad incoming/outgoing Polygon recipient queries exceeded the anonymous provider 20,000-result limit. These errors establish no recipient-history coverage. The narrower terminal-context package supplies bounded follow-up observations.

Requests, raw responses and capture metadata are retained with a saved-byte SHA-256 manifest. Acquisition used anonymous public sources. Successful state, event coverage, receipt verification, token backing and accepted settlement are separate checks.
