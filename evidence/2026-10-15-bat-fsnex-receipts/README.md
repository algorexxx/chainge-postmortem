# bat-fsnex-receipts

Public FSNEX transaction-detail records for every distinct transaction in the BAT Fusion issuance/destruction CSV. Original bytes preserve raw logs, success status and calldata. The fsnex-transaction importer validates completeness and identity. This is receipt-derived explorer evidence from the same infrastructure as the recovered node, not independent-provider corroboration.

See [the public workflow](../../research/fsnex-public-workflow.md). SHA-256 checks byte integrity, not source truth.
